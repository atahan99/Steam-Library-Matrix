# Brand icons

Mono SVGs from [thesvg.org](https://thesvg.org) that use `currentColor`. Nothing loads these files at runtime: the app draws the same marks inline through `BrandIcon` in `src/components/icons/brand-icon.tsx`. They are kept as reference copies.
