# Brand icons

SVGs from [thesvg.org](https://thesvg.org) (mono variants, `currentColor` for theme). Runtime UI uses inline React components in `src/components/icons/brand-icon.tsx`; these files are reference copies.

Used in the dashboard (nav, tables) and the landing/About **Library Orbit** (`src/content/library-orbit.ts`).

| File | Slug | Variant |
|------|------|---------|
| `steamdb.svg` | steamdb | mono |
| `protondb.svg` | protondb | mono |
| `steam-deck.svg` | steam-deck | mono |
| `apple.svg` | apple | mono |

`apple.svg` is also copied to `public/icons/platforms/apple.svg` for Mac platform badges.
