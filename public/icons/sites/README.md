# Source site icons

Real logos of the data sources, bundled because hotlinking them is blocked or breaks. `SOURCE_ICON` in `src/lib/sources/source-icon-config.ts` maps each source to its file, and the Library Orbit and the source links in tables use them. A source without an entry gets no icon. Trademarks belong to their owners.
